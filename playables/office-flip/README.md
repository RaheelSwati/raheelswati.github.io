# Office Flip playable ad

This is the lightweight HTML5 playable used by the Office Flip cross-promotion URL.

Gameplay loop: client brief → clear three messes → drag desk, chair and plant into valid zones → rotate chair → Maya reaction → install CTA.

The source is responsive in portrait and landscape, has no external JavaScript or font dependencies, starts audio only after interaction, and supports Google `ExitApi.exit()` with a normal store-link fallback.

The standalone advertising-network package is maintained at `Tools/Marketing/PlayableAds/OfficeFlip/OfficeFlip_PlayableAd.zip` in the Unity workspace. Its `index.html` is at the root of the ZIP.
